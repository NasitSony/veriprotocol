## Rust Concepts Learned

### Ownership

A String owns heap-allocated memory.

Ownership can move:

payload
→ Message
→ Network Queue
→ Caller

After ownership moves, the previous owner cannot access the object.

### Borrowing

Using:

&Message

allows temporary read-only access without transferring ownership.

### &self vs &mut self

&self

* read-only access

&mut self

* exclusive mutable access

Used &mut self to update node state when receiving messages.

### String vs &str

&str

* borrowed
* immutable
* static string data

String

* owned
* heap allocated
* mutable
* participates in ownership transfer

---

## Key Insight

Ownership transfer can be viewed as responsibility transfer.

Examples:

Queue → Worker

Scheduler → Executor

Network → Node

Rust enforces ownership transitions at compile time and prevents ambiguity about who is responsible for an object.
